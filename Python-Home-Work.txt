Решения заданий

1. main.py: первые 5 задач по основам и 5 задач по коллекциям оформлены
   закомментированными блоками. Чтобы запустить отдельный блок, снимите с него
   префикс # и временно закомментируйте активную самостоятельную работу.
   Закомментированный блок можно также скопировать в отдельный .py файл.
2. notes.txt и books.json: примеры файлов из заданий 3 и 4.
3. Активная часть main.py: менеджер задач с регистрацией, ролями пользователя
   и менеджера, обычными и срочными задачами. Запуск: python main.py.
   Данные сохраняются рядом с main.py в data.json после каждого изменения.
   Обычный пользователь видит свои задачи; менеджер также видит и завершает все.
   Пароли хранятся как PBKDF2-хеш с солью. Роль выбирается при регистрации
   для демонстрации требований учебного задания.
4. bookspace/: самостоятельный Django-проект. Инструкция — bookspace/README.txt.
5. bookspace.zip: архив Django-проекта без виртуального окружения.

Исходные main.py и Python-Home-Work.txt были пустыми.
Скриншот сайта нужно получить после установки Django и requests и запуска
с доступом к интернету. В текущем окружении зависимости отсутствуют,
а загрузка через pip недоступна из-за сетевого ограничения.
